# portfolio
# 🌐 Athish MA — Cloud & AI Engineer Portfolio

This is a **cloud-focused portfolio website** built to showcase hands-on experience in **AWS architecture, DevOps, and data engineering projects**.

The project demonstrates real-world cloud concepts such as **3-tier architecture, serverless systems, and data lake pipelines**.

---

## 🚀 Purpose

* Showcase practical AWS project experience
* Demonstrate cloud architecture understanding
* Present technical skills for cloud/DevOps roles
* Serve as a deployable static website

---

## 🧠 Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling
* **JavaScript (Vanilla)** – Functionality

---

## 📂 Project Structure

```
portfolio/
│── index.html     # Main application structure
│── style.css      # Styling
│── script.js      # Logic and interactivity
```

---

## ⚙️ Core Functionalities

### 1️⃣ Loader Simulation

Simulates cloud environment initialization with staged messages.

---

### 2️⃣ Dynamic Role Rendering

JavaScript-based typewriter logic to rotate roles:

* Cloud Engineer
* AWS Architect
* Data Engineer

---

### 3️⃣ AWS Architecture Representation

Includes structured visualization of:

* EC2, RDS, S3
* Lambda, API Gateway
* Route 53, CloudFront
* IAM & VPC

---

### 4️⃣ Scroll-Based Rendering

Uses **Intersection Observer API** to trigger content visibility on scroll.

---

### 5️⃣ Event-Based Interactions

* Hover-based tooltips
* Navigation highlighting
* Mobile menu toggling

---

### 6️⃣ Background Processing

* Canvas-based particle rendering
* Continuous animation loop

---

## ☁️ Cloud Concepts Demonstrated

* 3-Tier Architecture
* Serverless Architecture (Lambda + API Gateway)
* CDN (CloudFront)

* IAM & Security Practices
